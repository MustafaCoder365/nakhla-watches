# NAKHLA · نخلة

موقع تجريبي لبراند ساعات عراقي (وهمي) باسم **نخلة**: هوية بنفسجي فوق بنفسجي ويا أخضر ليموني نيون، والذهبي بس على الساعة.

- الهيرو ويا شريط متحرك ليموني
- المجموعة: الكلاسيك الذهبية، الرياضية الزيتونية، اللؤلؤية
- الطلب على واتساب ويا خيار الحفر على ظهر الساعة

رقم الواتساب في `WA` داخل `index.html`. صور المنتجات مولّدة بالذكاء الاصطناعي.

صُمّم بواسطة [TrueStackit](https://truestackit.com).
